이 파일이 하는 일

이 페이지는 브라우저 안에서만 도는 도구입니다. 붙여 넣은 내용을 이 브라우저 안에서 정리해 HTML 파일로 저장합니다.

붙여 넣은 내용을 어디로도 보내지 않으며, 일체의 데이터를 수집하지 않습니다.

접근하는 주소: 이미지를 내려받을 때만 https://qvra.pages.dev · https://vqrn.pages.dev. 그 외 주소로는 브라우저가 요청을 막도록 파일 안에 설정(Content-Security-Policy)되어 있습니다.

확인 방법: 이 페이지에서 Ctrl + U(소스 보기)를 누르시면 코드 전체를 읽으실 수 있습니다. 브라우저에서 F12 → 네트워크 탭을 열면 실제 요청을 볼 수 있습니다.

원본 코드: https://github.com/friedlemon2139-code/ChatArchive

파일로 내려받아 쓰기: luna-tool.html — 코드까지 한 장에 담긴 파일입니다. 내려받아 인터넷 없이 사용하실 수 있습니다.

루나톡 대화 저장 (붙여넣기)

루나톡 대화 화면의 글을 복사해 붙여 넣으면 HTML 파일로 저장합니다.

  1. ①루나톡에서 저장할 대화 화면을 엽니다. 화면에 불러와진 메시지가 저장되므로, 대화 전체를 저장하려면 위로 스크롤해 이전 메시지가 모두 화면에 불러와진 상태로 만듭니다.
  2. ②대화 영역의 빈 곳을 한 번 클릭한 뒤 Ctrl + A(전체 선택) → Ctrl + C(복사)로 복사합니다. 메시지 글자 위를 클릭한 상태에서는 그 메시지 하나만 선택될 수 있습니다.
  3. ③아래 칸에 Ctrl + V로 붙여 넣습니다.
  4. ④미리보기에서 턴 수와 이름을 확인하고 파일 만들기를 누릅니다.

저장되는 내용

대화 전체, 화자 구분, 글 서식, 상태창 블록, 이미지가 저장됩니다. 이미지는 파일 안에 포함되며 같은 이미지는 한 번만 들어갑니다. 작성 시각은 복사본에 없어 포함되지 않습니다. 붙여 넣은 내용이 글만일 때는 글만 저장됩니다.

데이터 처리

이 도구는 일체의 데이터를 수집하지 않습니다. 붙여 넣은 글은 이 페이지 안에서만 처리되며 어디로도 전송되지 않습니다. 만들어진 파일은 사용 중인 컴퓨터의 다운로드 폴더에 남습니다.

이 페이지는 루나톡에 접속하지 않습니다. 붙여 넣은 내용에 이미지 주소가 있을 때만, 그 이미지를 파일에 넣기 위해 해당 주소에서 이미지를 내려받습니다. 내려받을 수 있는 주소는 맨 위 이 파일이 하는 일 칸에 적힌 곳뿐이며, 그 밖의 주소로는 브라우저가 요청을 막습니다(Content-Security-Policy). 막힌 이미지는 저장을 멈추지 않고 파일 안에 내장 실패로 남습니다.
