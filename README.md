# ChatArchive — 루나톡 대화 저장 도구

루나톡 **본인 대화 기록**을 HTML 파일 하나로 저장하는 도구입니다.
저장된 파일은 브라우저로 열며, 대화 본문·화자 구분·서식·이미지·원본 데이터가 파일 안에 들어 있어 인터넷 연결 없이 열립니다.

이 저장소는 배포 파일이 어떤 코드에서 나왔는지 누구나 확인할 수 있도록 공개합니다.

## 사용 방법

**1. 도구 열기** — 둘 중 편한 쪽

- 웹에서 바로 쓰기: **https://friedlemon2139-code.github.io/ChatArchive/** 를 엽니다. 설치나 내려받기 없이 그 페이지에 붙여 넣으면 됩니다.
- 파일로 내려받아 쓰기: 아래 "파일 내려받기" 절차대로 `luna-tool.html`을 받아 더블클릭합니다. 내려받아 인터넷 없이 사용하실 수 있습니다. 코드가 압축되지 않은 채 그 파일 안에 들어 있습니다.

<details>
<summary><b>파일 내려받기 — 깃허브가 처음이라면</b></summary>

1. 이 저장소 첫 화면(파일 목록)에서 `dist` 폴더를 클릭한 뒤 `luna-tool.html`을 클릭합니다.
2. 파일 내용이 보이는 화면 오른쪽 위에 **아래쪽 화살표 모양 아이콘(Download raw file)** 이 있습니다. 그것을 누르면 `luna-tool.html`이 브라우저 다운로드 폴더에 저장됩니다. ("Raw" 글자 버튼을 눌러 코드가 화면에 펼쳐지면, `Ctrl+S`로 저장해도 됩니다.)
3. 저장된 `luna-tool.html`을 더블클릭하면 브라우저에서 도구가 열립니다.

바로가기: https://github.com/friedlemon2139-code/ChatArchive/blob/main/dist/luna-tool.html
</details>

**2. 대화 복사**
- 루나톡에서 저장할 대화 화면을 엽니다. 화면에 불러와진 메시지가 저장되므로, 대화 전체를 저장하려면 위로 스크롤해 이전 메시지가 모두 화면에 불러와진 상태로 만듭니다.
- 메시지의 회색 글 상자 **안이 아니라 바깥쪽 빈 영역**을 한 번 클릭한 뒤, `Ctrl+A`(전체 선택) → `Ctrl+C`(복사)합니다. 글 상자 안을 클릭하고 전체 선택하면 그 메시지 하나만 선택됩니다.

**3. 붙여 넣고 저장**
- 도구의 입력 칸에 `Ctrl+V`로 붙여 넣습니다. 아래 미리보기에 인식 결과(턴 수, 캐릭터 이름, 이미지 수)가 표시됩니다.
- `파일 만들기`를 누르면 이미지를 내려받아 파일을 만들고 파일 크기를 보여 줍니다. `저장`을 누르면 브라우저 다운로드 폴더에 HTML 파일 하나가 저장됩니다.

**데이터 처리**
- 로컬에서 이용하는 파일이므로 붙여 넣은 내용은 어떤 데이터도, 누구에게도 공유되지 않습니다. 일체의 데이터를 수집하지 않습니다.
- 인터넷은 대화에 적힌 이미지 주소에서 이미지를 내려받아 파일에 넣는 용도로만 사용됩니다. 그 외 주소로의 요청은 파일 안의 브라우저 설정(CSP)이 막습니다.
- 이미지는 저장하는 시점에 이미지 주소가 살아 있어야 포함됩니다. 작성 시각은 복사본에 없어 포함되지 않습니다.
- PC 브라우저(크롬·엣지·파이어폭스)에서 이용합니다.

## 안전에 대해

### 이 도구가 하는 일 / 하지 않는 일
- 일체의 데이터를 수집하지 않습니다. 모든 처리는 사용자의 브라우저 안에서 이루어지고, 결과는 브라우저 다운로드로 사용자 컴퓨터에만 저장됩니다.
- 붙여 넣은 내용을 어디로도 전송하지 않습니다.
- 플랫폼 서버에 접근하지 않습니다. 이용자가 복사해 붙여 넣으신 내용만 처리합니다.
- 이미지: 대화에 적힌 이미지 주소에서 내려받아 파일에 넣습니다. 허용된 호스트(아래 CSP 참조) 외에는 브라우저가 요청을 막습니다.

### 1. 통신 제한은 브라우저가 강제합니다 (CSP)

`dist/luna-tool.html`과 저장되는 모든 결과 파일의 `<head>` 첫 줄에 `Content-Security-Policy`가 들어 있습니다.

- 도구 파일: `default-src 'none'` — 이미지 내려받기(`img-src`, `connect-src`)만 지정된 호스트에 허용, `form-action 'none'`으로 전송 자체를 차단.
- 결과 파일: `default-src 'none'; img-src data: blob:` — 열 때 외부 요청이 한 건도 나가지 않습니다.

파일을 메모장으로 열어 첫 몇 줄에서 확인할 수 있고, 브라우저 F12 → 네트워크 탭에서 실제 요청을 볼 수 있습니다.

### 2. 코드를 읽을 수 있습니다

`dist/readable/`에 압축하지 않은 빌드 산출물이 있습니다. `dist/luna-tool.html` 안의 스크립트도 압축하지 않은 코드입니다. 원본은 `src/`입니다.

### 3. 빌드를 재현할 수 있습니다

빌드는 결정적(deterministic)이라 같은 소스에서 같은 바이트가 나옵니다.

```
npm ci
npm run build      # dist/ 를 다시 만들고 각 파일의 SHA-256을 출력합니다
```

출력된 해시가 아래 표(및 배포 공지)와 같으면 배포 파일이 이 소스에서 나온 것입니다.

## 저장되는 파일

- `{접두어}_{플랫폼}_{대화제목}_{날짜}.html` 하나. 브라우저로 엽니다.
- 파일 안 버튼: `Markdown 저장`(글과 이미지를 zip으로), `원본 JSON 저장`, 턴마다 `원문 복사`, 코드블록 `복사`. 브라우저 인쇄로 PDF 저장 가능.
- 파일 안 `<script type="application/json" id="geas-export">`에 원본 데이터(JSON)가 들어 있습니다.

## 디렉터리

```
src/         원본 코드 (luna-paste.js 붙여넣기 파서, paste-page-core.js 화면 흐름, viewer/, …)
build.mjs    빌드 스크립트 (esbuild 하나만 사용)
dist/        빌드 산출물 — 배포 파일과 readable/ 판
docs/        웹페이지 판 (GitHub Pages)
```
